# StatSkill AI — Internationalization Contract

## Locales

- `en` — English
- `hi` — Hindi / हिन्दी
- `te` — Telugu / తెలుగు

## Rules

1. No hard-coded user-facing strings in application components.
2. Use stable semantic translation keys, e.g. `dashboard.overview.title`.
3. Persist the selected locale per authenticated user.
4. First launch asks for language before entering the application.
5. Returning users use their persisted locale.
6. Global language switching is always available from the application shell.
7. Interface locale and learning-content locale are independent.
8. Missing translations fall back safely to English while preserving the selected UI locale.
9. AI assistant defaults to the selected locale unless the user explicitly requests another language.
10. Assessment questions must preserve semantic equivalence across translated versions.

## Suggested resource layout

`messages/en.json`
`messages/hi.json`
`messages/te.json`

## QA requirements

Every critical user journey must be exercised in all three locales, including long Hindi/Telugu labels, navigation, forms, validation messages, dashboard cards, assessment options, and AI responses.
