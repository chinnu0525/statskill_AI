# StatSkill AI

AI-powered Skill Intelligence & Learning Platform for statistical officials.

## Product direction

StatSkill AI combines competency assessment, skill-gap analysis, personalized learning recommendations, AI-generated assessments, AI tutoring, and organizational analytics.

### Supported languages
- English
- हिन्दी
- తెలుగు

## Engineering principles

- `main` is production-ready and protected by pull-request workflow.
- Feature work happens on `agent/*` branches.
- Agents communicate through GitHub issues, pull requests, and `/docs` + `/agent-reports` artifacts.
- AI outputs are grounded in approved learning material where applicable.
- iGOT and NSSTA integrations use adapters so demo/mock integrations can be replaced by official APIs later.

## Status

Project initialization and product/design architecture in progress.
